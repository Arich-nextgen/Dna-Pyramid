# PYRAMID DNA

Существующее приложение для анализа финансовых предложений RU/KZ. FastAPI и движок Pyramid DNA сохранены; изменения движка ограничены извлечением ролей и валют сумм, отрицаний, объяснимых диапазонов исходного текста и детализацией существующего сравнения.

## Запуск

```bash
./start.sh
```

Локальный интерфейс: http://127.0.0.1:8000/app/ · API: http://127.0.0.1:8000/docs

Для Sites React запускает исходный FastAPI в Pyodide WebWorker. Первая команда анализа загружает среду Python; обычный главный экран не показывает служебный статус и не делает запросов к API при открытии. Веб-версия хранит рабочие дела в SQLite/IndexedDB текущего браузера. Локальный FastAPI использует серверный SQLite.

## Изменения

- Подсветка точных фрагментов из Python-ответа, с диапазонами UTF-16, поверх редактируемого поля; расчётные позиции не подменяются эвристикой интерфейса.
- Отдельные загрузчики UTF-8 TXT для A и B в режиме сравнения, включая BOM, показ имени, ограничения размера, редактирование и удаление содержимого.
- Круговая шкала отображает реальные `risk_points`; список рядом показывает фактические баллы правил, а не вероятность.
- Таблица сравнения показывает значения и нормированный вклад в реальный итоговый коэффициент. Неизвестные данные не превращаются в совпадение; валюты не конвертируются.
- Убраны постоянные технические статусы, подпись о 720 примерах с главного экрана и повторные ссылки внизу; сами датасет, страница качества, API и сохранённые дела сохранены.
- Компактная методика и страница качества с реальными отчётами из `artifacts/`.
- Режим «Переписка» на экране проверки: TXT или ручной ввод, предпросмотр и редактирование сообщений, осторожное восстановление нескольких механизмов и точная связь каждого доказательства с `message_id`.
- `POST /api/v1/analyze/conversation` работает в локальном FastAPI и в том же Pyodide Worker. Повторы не суммируют риск; предупреждения, обычные покупки и неподтверждённые цитаты исключаются из механизма.

## Проверка качества

Автоматические проверки: `36` Python-тестов, TypeScript, TXT-импорт, production build и сквозной запуск настоящего FastAPI в Pyodide. Сквозной тест охватывает обычный анализ, переписку и provenance доказательств, поиск, сравнение, SQLite CRUD, оценку и quality artifacts.

`artifacts/benchmark_results.json` — одинаковые пары для structural matcher и word TF-IDF на полностью синтетических финансовых предложениях high/medium: 2 016 train, 672 validation, 672 test. Пороги выбраны на validation. На test DNA: precision `74.2%`, recall `78.9%`, FPR `27.4%`, F1 `76.5%`; TF-IDF: precision `74.0%`, recall `86.6%`, FPR `30.4%`, F1 `79.8%`. DNA имеет немного меньший FPR, но уступает по recall и F1; превосходство не заявляется. Старый результат с порогом `0.0` и FPR `100%` сохранён в `artifacts/benchmark_results_2026-10-20_fpr100.json`. Причиной была неверная постановка пар: low-risk предупреждения и покупки размечались как положительные совпадения по общему synthetic `mechanism_id`, хотя matcher намеренно исключает их из задачи сопоставления финансовых предложений.

`artifacts/conversation_benchmark_results.json` — 12 полностью синтетических переписок. В текущем наборе точность числа механизмов, размеченных финансовых полей и диапазонов доказательств — `100%`; False Mechanism Merge Rate — `0%` на двух сценариях с независимыми предложениями. Малый проектный набор не является оценкой точности на реальных чатах.

`artifacts/public_challenge_results.json` — диагностическое покрытие 15 исследовательских пересказов официальных публикаций: 45/45 явно размеченных положительных признаков, 15/15 с полным покрытием ожидаемых полей. Это не precision/FPR, не слепой holdout и не точность на исходных сообщениях WhatsApp/Telegram. Поля без явного упоминания не считались отрицательными. Ограничения источников отражены в самом отчёте.

`artifacts/public_final_holdout_results.json` получен один раз после фиксации движка `a43a68f` (engine SHA в отчёте). На 5 закрытых кейсах извлечено 16/18 проверок (88.9%); 4/5 кейсов полностью покрыты. Два пропуска — приглашения и период в одном кейсе. Это небольшой предметный набор, не оценка population accuracy и не основание менять пороги. После проверки движок не менялся.

## Данные и ограничения

Все 720 встроенных примеров синтетические. Оценка риска — набор объяснимых признаков, а не вероятность нарушения или юридический вывод. Извлечённые условия и сравнение требуют проверки человеком. Веб-версия не синхронизирует пользовательские дела между устройствами. Отчёты можно экспортировать из интерфейса.

OCR работает локально в браузере через Tesseract.js 7.0.0 и официальные
`tessdata_fast`-модели `rus` и `kaz`. Перед распознаванием приложение применяет
EXIF-ориентацию к пикселям, увеличивает мелкий текст, корректно обрабатывает
тёмные скриншоты и при явно плохом результате проверяет альтернативные повороты.
Пользователь видит уверенность и предупреждение качества, может повернуть и
обрезать изображение, отредактировать текст и только затем передать его в
анализ. Метрики на синтетических регрессионных изображениях находятся в
`artifacts/ocr_benchmark_results.json`; они не являются метриками реальных
WhatsApp или Telegram переписок.
